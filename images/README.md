# Slide Images

Drop slide graphics and screenshots here. The Markdown decks reference images two ways:

- **Placeholders:** lines like `<!-- image: describe the visual -->` mark where a
  screenshot or diagram should go. A designer or instructor fills these in before
  delivery. See `IMAGE-MANIFEST.md` for the consolidated shopping list.
- **Embedded images:** once a file exists here, reference it from a deck with
  `<img src="../images/your-file.png" style="width:70%;"/>`.

Keep filenames descriptive and lowercase-with-dashes (e.g. `custom-gpt-builder.png`).
Prefer real tool screenshots for the "how" and simple diagrams for the "why."
