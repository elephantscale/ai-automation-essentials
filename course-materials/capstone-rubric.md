# Capstone Rubric

| Criterion | Strong | Needs Work |
|-----------|--------|------------|
| Business fit | Solves a real workflow problem | Workflow is vague or low-value |
| Prompt quality | Clear task, context, output, constraints | Prompt is ambiguous |
| Tool selection | Tools match the task and environment | Tools are chosen without rationale |
| Artifact quality | Output is usable with light review | Output needs major rework |
| Safety controls | Privacy, approval, and verification are built in | Risks are not addressed |
| Rollout plan | Clear 30-day next steps | No practical adoption plan |
