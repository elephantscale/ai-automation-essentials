# Document And Data Analysis Checklist

Before upload:

- Confirm the material is approved for the selected tool.
- Remove confidential or regulated data unless the environment is approved.
- Define the question before uploading files.

During analysis:

- Ask for extracted facts before conclusions.
- Ask the assistant to cite source sections or rows.
- Separate observations from recommendations.
- Check calculations and totals.

Before use:

- Verify high-impact claims.
- Confirm charts and summaries match the source.
- Keep a copy of the prompt and output for review.
