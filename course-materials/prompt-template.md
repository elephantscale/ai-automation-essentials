# Prompt Template

## Task

What should the assistant do?

## Context

What background, source material, audience, or business situation matters?

## Input

Paste or attach only approved content.

## Output Format

Specify the exact format:

- Bullets
- Table
- Email
- JSON-like fields
- Slide outline
- Checklist

## Constraints

Include length, tone, exclusions, brand voice, required terms, or forbidden terms.

## Review Instructions

Ask the assistant to:

- State assumptions
- Identify missing information
- Quote or cite source material when working from documents
- Mark uncertain claims for review
